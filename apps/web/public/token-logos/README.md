# Token Logo Assets

Place token logos in chain-specific folders to match `src/lib/bloxologyTokenList.js`.

Suggested structure:

- `token-logos/base/weth.png`
- `token-logos/base/usdc.png`
- `token-logos/base/dai.png`
- `token-logos/base/usdt.png`
- `token-logos/base/magb.png`
- `token-logos/base/plei.png`
- `token-logos/base/tosh.png`
- `token-logos/base/blush.png`
- `token-logos/base/alb.png`
- `token-logos/base/meow.png`
- `token-logos/ethereum/weth.png`
- `token-logos/ethereum/usdc.png`
- `token-logos/ethereum/dai.png`
- `token-logos/ethereum/usdt.png`
- `token-logos/polygon/mag.png`
- `token-logos/polygon/pink.png`
- `token-logos/kava/blush.png`
- `token-logos/kava/prin.png`

Tips:

- Use square images (256x256 or 512x512).
- Prefer transparent PNG or clean SVG.
- Keep filenames lowercase.
