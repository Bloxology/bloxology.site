# Bloxology Web App (`bloxology.site`)

**Bloxology** is a web-based payment and integration platform designed to help small businesses accept modern digital payments with zero friction. This repository contains the source code, assets, and deployment configurations for the official website and web app.

---

## 🚀 Key Features

* **Instant Digital Payments:** Enables small businesses and local shops to seamlessly accept Bloxology payments.
* **Low Transaction Friction:** Streamlined checkout process to reduce cart abandonment and increase conversion rates.
* **Revenue & Analytics Dashboard:** Clear tracking and real-time management of incoming sales.
* **Developer-Friendly Integration:** Lightweight components and API connectors built for easy integration and scalability.

---

## 🛠️ Tech Stack

* **Frontend:** Framework/Library (e.g., Next.js / React / Vue)
* **Styling:** CSS Framework / Tailwind CSS
* **Hosting & Deployment:** GitHub Pages / Vercel / Netlify

## 💻 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:

* [Node.js](https://nodejs.org/?utm_source=gemini) (v18 or higher)
* `npm` or `yarn` / `pnpm`

### Local Setup

1. **Clone the repository:**
```bash
git clone https://github.com/Bloxology/bloxology.site.git
cd bloxology.site

```


2. **Install dependencies:**
```bash
npm install

```


3. **Run the development server:**
```bash
npm run dev

```


4. **Open in browser:**
Navigate to `http://localhost:3000` to see the site running locally.
